# Портфолио

## Запуск

```sh
npm install
npm run dev
```

Для production-сборки запустите `npm run build`. Готовые файлы будут в `dist/`.

## Содержание

Измените значения в `portfolio.js`: имя, вводный текст и содержание раздела «Обо мне». Направления проектов и технологии можно редактировать в массивах `about.topics` и `about.technologies`. Список технологий не отображается, пока массив пуст.

В `work.projects` можно добавлять и удалять проекты. Укажите `url`, чтобы название проекта стало ссылкой; оставьте пустую строку, если ссылка не нужна. Для open-source проектов, в которые вы внесли вклад, установите `openSourceContribution: true` — рядом с проектом появится отметка. При `false` или отсутствии поля отметка не отображается.

Для опыта работы добавьте записи в `work.experience`. Каждая запись — объект с полями `role` (должность), `company` (компания), `period` (период работы) и `description` (задачи и результаты). Раздел опыта работы отображается только при наличии записей.

Контакты в `contact.links` состоят из `label` (название) и `url` (адрес, например ссылка или `mailto:`). Раздел и ссылка в навигации скрыты, если список пуст.
